# Threat Model: `raksa-siem` v0.3.0

This document captures trust boundaries, attacker capabilities considered, and implemented fail-closed controls in `raksa-siem`.

## Trust Boundaries

1. **Untrusted Log, Gzip & Network Telemetry Inputs**: Log files, `.gz` archives, tailed streams, Syslog UDP/TCP datagrams/connections, and HTTP `/api/v1/ingest` payloads frequently carry attacker-controlled paths, usernames, hosts, HTML characters, and terminal escape bytes.
   - *Control*: Terminal/table formatters sanitize control bytes via `report.SanitizeTerminal`. Offline HTML attack-graph exports escape all dynamic node, target, title, and evidence text via Go's `html.EscapeString` / safe `<script>` JSON escaping and execute strictly inline with zero external CDN scripts or requests. Decompression enforces a strict `64 MiB` byte cap in Go and Python. HTTP ingest caps bodies at `2 MiB`; Syslog UDP caps datagrams at `64 KiB`, and Syslog TCP caps line length (`256 KiB`), concurrent connections (`128`), and idle timeouts (`60s`).
2. **Policy, Sigma YAML & Hot-Reload Config**: Misconfigured waivers, expired suppressions, invalid regexes/CIDRs, malformed Sigma AST conditions, failed reloads, or plaintext remote webhook URLs could blind detection or leak incident metadata.
   - *Control*: `policy.ValidateAndCompile()` and `sigma.ParseBytes()` fail closed on invalid syntax, expired waivers (`YYYY-MM-DD`), invalid route targets (`ValidateHTTPSOrLocalhostURL`), or out-of-range retry/retention settings. `ReloadPolicy` (via `SIGHUP` or `POST /api/v1/reload`) compiles and validates the candidate policy cleanly before atomically swapping engine and router state, preserving prior active policy on error.
3. **HTTP/TLS Server, mTLS & Scoped RBAC (`raksa-siem serve`)**: Exposed on network interfaces to ingest telemetry, query incidents/search, manage cases, and trigger reloads.
   - *Control*: Slowloris-hardened timeouts (`ReadHeaderTimeout: 5s`, `ReadTimeout: 15s`, `WriteTimeout: 15s`, `IdleTimeout: 60s`). Optional TLS enforces minimum TLS 1.2; supplying `--tls-client-ca` enforces `tls.RequireAndVerifyClientCert` mTLS (failing closed at startup if server cert/key are absent). Scoped credentials (`--ingest-key-env`, `--read-key-env`, `--admin-key-env`, and legacy full-access `--api-key-env`) fail closed at startup when referenced env vars are empty, validate via `crypto/subtle.ConstantTimeCompare`, enforce least-privilege route permissions (`403 Forbidden`), and drain up to `64 KiB` on rejected requests to prevent clean HTTP clients from hitting TCP resets.
4. **Tamper-Evident Audit Ledger & Cross-Language Verification (`internal/ledger`, `sdk/python`)**: Post-incident disk tampering could alter historical logs, finding evidence, or analyst triage notes.
   - *Control*: Every event, finding, and `case_update` entry is written sequentially into date-partitioned `siem-YYYY-MM-DD.ndjson` segments with a continuous `SHA-256(seq|timestamp|kind|prev_hash|<compact_payload>)` chain rooted at a 64-zero genesis hash. Both Go (`verify-ledger`, `siem_verify_ledger`, `/api/v1/ledger/verify`) and zero-dep Python (`verify_ledger_dir`) verify exact chain continuity and hash integrity bit-for-bit across segments.
5. **Alert Sinks, Retry Backoff, DLQ & Secrets**: Webhook HMAC keys, Telegram tokens, and PagerDuty/Opsgenie routing keys must stay out of config literals and logs, while transient sink outages must not drop critical alerts silently.
   - *Control*: Policies reference environment variable names (`secret_env`, `token_env`) only; client errors redact `/bot<token>` paths; failed deliveries retry with bounded exponential backoff (`max_retries` `0..5`) before appending structured failures to an append-only NDJSON dead-letter queue (`dlq_path`) replayable via `ReplayDLQ`.
6. **Memory Exhaustion & Supply Chain Footprint**: Minimize runtime resource exhaustion and third-party supply-chain exposure.
   - *Control*: Correlator sliding windows prune expired state and cap partial sequence chains (`32` per key); HTTP server caps retained in-memory events (`50,000`) and incidents (`10,000`); Go module uses a single external dependency (`gopkg.in/yaml.v3 v3.0.1`); Python SDK has zero runtime dependencies (`dependencies = []`); `Dockerfile` builds a static `CGO_ENABLED=0` binary inside `gcr.io/distroless/static-debian12:nonroot` (`65532:65532`).

## Scope & Boundaries

- The hash-chained ledger provides tamper-evidence against silent file edits on disk; preventing root-level deletion of an entire local filesystem remains an OS/immutable-backup concern.
- Mutual TLS (`--tls-client-ca`) and scoped RBAC protect network transport and API boundaries once configured; operators are responsible for provisioning non-loopback certificates and distinct token scopes in production environments.
